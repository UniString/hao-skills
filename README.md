# skills

我自己在用的几个 AI 助手技能（skill）。

## 什么是 skill

skill 是一段写给 AI 助手看的说明书。AI 助手（比如 ZCode、Claude Code）在回答之前会先读这份文件，然后按里面写的规矩来做事。所以它其实就是一份 markdown 文档，放在固定的目录里就能被读到，没有代码，也不需要安装依赖。

## 目录里有什么

| 目录 | 什么时候用 |
| --- | --- |
| `plain-chinese-chat/` | 要 AI 用中文跟你对话时：解释概念、汇报进展、指导你去配置或审批某件事 |
| `plain-chinese-docs/` | 要 AI 写或改中文技术文档时：README、设计说明、变更记录、调研笔记这类给人看的 markdown |

这两份是同一个毛病的两个版本。AI 默认输出容易堆名词、中英混杂、上来就说"对 X 进行 Y 化"，读的人得自己补背景。这两份文件把"怎么写人话"拆成了可以照着做的几条规则。

## 怎么用

把想用的目录整个拷到 AI 助手读 skill 的位置。以 ZCode 为例，位置是：

- 只给当前项目用：项目目录下的 `.zcode/skills/`
- 给这台机器上所有项目用：`~/.agents/skills/`

拷完重启会话，或者新开一个会话，助手就会读到。具体路径各家工具不一样，看对应工具的文档。
