# hao-skills

个人 AI 助手 skill 集合。一个目录一个 skill，入口是目录下的 `SKILL.md`。

## 内容

| 目录 | 用途 |
| --- | --- |
| `plain-chinese-chat/` | 需要模型输出朴实无华的中文对话时 |
| `plain-chinese-docs/` | 需要模型输出一份朴实无华的中文文档时 |

## 使用

把要用的目录复制到助手读取 skill 的位置。

ZCode 支持两个位置：

- 单个项目：项目目录下的 `.zcode/skills/`
- 整台机器：`C:\Users\<用户名>\.agents\skills\`，Linux 和 macOS 上是 `~/.agents/skills/`

其他工具查各自的文档。
