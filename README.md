# hao-skills

两个中文表达规则，给我在用的 AI 助手看，用来约束它用中文说话、写中文文档时的用词和句式。

## 什么是 skill

skill（直译"技能"）是一份写给 AI 助手看的说明书。助手读到这份文件之后，后面回答就按里面写的规矩来。它本身只是 markdown 文本，没有代码，也不用装依赖。

这个仓库里每个目录就是一个 skill，入口都是目录下那个 `SKILL.md`。

## 包含哪两个

| 目录 | 什么时候让它生效 |
| --- | --- |
| `plain-chinese-chat/` | 助手用中文跟你对话时：解释概念、汇报进展、教你怎么配置或审批一件事 |
| `plain-chinese-docs/` | 助手写或改中文技术文档时：README、设计说明、变更记录、调研笔记这类给人看的 markdown |

两个解决的是同一个问题：助手的默认输出爱堆名词、中英夹杂，读的人得自己补背景才知道它在说什么。区别只在场景——聊天里话要短，文档里要能脱离上下文独立读懂。

## 怎么用

1. 把要用的目录整个复制到助手读 skill 的位置。
2. 新开一个对话，助手就会读到。

以 ZCode 为例，位置有两个：

- 只给一个项目用：项目目录下的 `.zcode/skills/`
- 给这台机器上所有项目用：`C:\Users\<你的用户名>\.agents\skills\`，Linux 和 macOS 上是 `~/.agents/skills/`

换别的工具，目录位置不一样，查它自己的文档。
